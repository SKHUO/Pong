# Pong 产品设计文档

## 1. 产品概述

Pong 是一款基于 Godot 的 2D 双人对抗小游戏。双方先各自选择角色，再控制分界线两侧的挡板反弹小球进行对战。游戏采用 1280×720 的 16:9 固定画面；界面较上一版更大，角色与小球尺寸不变。

## 2. 游戏流程

1. 启动后先进入角色选择页。
2. 两名玩家各自选择角色。
3. 按下空格，双方以当前所选角色进入对战。
4. 开局小球附着在 Player 1 身上，等待其发球。
5. 小球出界后，该侧玩家输掉本轮，对方获胜。
6. 下一轮双方回到初始位置，由上一轮赢家发球；角色保持不变。

## 3. 角色选择页

| 项目 | 设计要求 |
| --- | --- |
| 布局 | 画面被中央分界线分为左右两半，左侧属于 Player 1，右侧属于 Player 2 |
| 角色选项 | 用不同颜色的方块表示；两侧的可选角色完全相同 |
| 排列 | 方块按网格排列，从左到右、从上到下依次摆放 |
| 默认选中 | 双方默认选中第一个角色 |
| Player 1 选中标记 | 蓝色方框，框住当前所选方块 |
| Player 2 选中标记 | 绿色方框，框住当前所选方块 |
| 开始提示 | 底部提示“空格 开始游戏” |

## 4. 角色列表

| 角色 | 说明 |
| --- | --- |
| 白色角色 | 初始角色，与上一版一致 |
| 红色角色 | 除颜色外，与白色角色完全相同 |

## 5. 对战画面

| 项目 | 设计要求 |
| --- | --- |
| 画面比例 | 16:9 |
| 背景 | 纯黑色，铺满整个游戏画面 |
| 分界线 | 白色纵向线，位于画面正中央，将游戏区域分为左右两半 |
| Player 1 挡板 | 纵向长方体，位于分界线左侧，颜色由所选角色决定 |
| Player 2 挡板 | 纵向长方体，位于分界线右侧，颜色由所选角色决定 |
| 小球 | 白色小方块 |

## 6. 操作方式

| 场景 | 玩家 | 操作 | 按键 |
| --- | --- | --- | --- |
| 角色选择 | Player 1 | 移动选择 | `W` / `S` / `A` / `D` |
| 角色选择 | Player 2 | 移动选择 | 方向键 `↑` / `↓` / `←` / `→` |
| 角色选择 | 双方 | 开始游戏 | 空格 |
| 对战 | Player 1 | 上、下、左、右移动 | `W` / `S` / `A` / `D` |
| 对战 | Player 2 | 上、下、左、右移动 | 方向键 `↑` / `↓` / `←` / `→` |
| 对战 | Player 1 | 持球时发球 | `J` |
| 对战 | Player 2 | 持球时发球 | 小键盘 `1` |

## 7. 核心玩法规则

1. 开局小球不自动发射，而是紧贴 Player 1 朝向 Player 2 的一侧，并随 Player 1 移动。
2. 持球方发球后，小球立即朝对手一侧运动，初速度方向与水平面的夹角随机。
3. Player 1 持球时按 `J` 发球；Player 2 持球时按小键盘 `1` 发球。
4. 玩家可以上下左右移动，但会被屏幕边界和中央分界线阻挡，不能越过分界线。
5. 小球碰到玩家时，水平分速度反向。
6. 小球碰到画面上边界或下边界时，竖直分速度反向。
7. 小球从左侧出界，Player 1 输、Player 2 赢；从右侧出界则相反。
8. 每轮结束后双方回到初始位置，下一轮由赢家持球并等待发球。

## 8. 验收标准

- 初始窗口为 1280×720，比上一版更大。
- 启动游戏后首先看到角色选择页，页面由左右两部分和中央分界线组成。
- 两侧可选角色完全相同，均以彩色方块表示，且排列规则一致。
- Player 1 的选中方块被蓝色方框标记，Player 2 的选中方块被绿色方框标记。
- 两名玩家可分别用各自按键移动选择，选中标记随之移动。
- 按下空格后，双方以当前所选角色进入对战，挡板显示对应角色颜色。
- 对战中仅包含黑色背景、一条中央分界线和两个玩家、一个小球等核心视觉对象。
- 开局小球附着在 Player 1 朝向对手的一侧并跟随其移动，不自动发球。
- Player 1 按 `J`、Player 2 按小键盘 `1` 时，仅持球方可以成功发球。
- 发球方向朝向对手，并带有随机上下角度。
- 小球与玩家、上下边界碰撞后，速度按规则正确反弹。
- 小球从任一侧出界后，判定该侧玩家输、对方赢；下一轮由赢家持球。
- 每轮角色颜色保持不变。

## 9. 项目维护

- 场景与脚本按角色选择、对战、共享组件、角色数据分类管理。
- 本次新增待发球、双方发球按键和回合胜负规则。
